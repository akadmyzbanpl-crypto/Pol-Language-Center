# آموزشگاه زبان پل (Pol Language Center)

سامانه جامع و هوشمند آموزش زبان انگلیسی، دوره‌های تخصصی آیلتس، کلاس‌های آنلاین زنده، فروشگاه کتاب و پنل‌های اختصاصی زبان‌آموز، استاد و مدیریت.

---

## 📌 ویژگی‌های کلیدی پروژه

- **صفحه اصلی مدرن و واکنش‌گرا (Responsive):** طراحی با ترکیب Tailwind CSS و React، هدر چسبنده (Sticky Header) با ناوبری سریع، کارت‌های معرفی خدمات و آمار موفقیت زبان‌آموزان.
- **کلاس‌های زنده و آنلاین (Live Virtual Classroom):** شبیه‌ساز کلاس زنده همراه با ویدیو استریم، تخته هوشمند و چت تعاملی هم‌زمان.
- **فروشگاه جامع کتاب و دوره‌ها:** سبد خرید پویا، درگاه پرداخت تستی، کدهای تخفیف و صدور آنی فاکتور.
- **سامانه‌های نقشی (RBAC):** 
  - پنل زبان‌آموز (مشاهده برنامه هفتگی، تکالیف، نمرات و کلاس‌ها)
  - پنل اساتید (حضور و غیاب، بارگذاری تکالیف، ارسال بازخورد)
  - پنل ادمین (گزارش‌های مالی، مدیریت کاربران، دوره‌ها، کتاب‌ها و اطلاع‌رسانی‌ها)
- **پشتیبانی کامل از زبان فارسی و تاریخ شمسی:** تقویم جلالی، اعداد فارسی و فونت Vazirmatn.

## 🚀 نحوه نصب و راه‌اندازی محلی (Local Setup)

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- مدیر بسته **npm** یا **yarn** یا **pnpm**
- ابزار **Git**

### مراحل اجرا
۱. مخزن پروژه را کلون کنید یا فایل ZIP را استخراج نمایید:
```bash
git clone https://github.com/USERNAME/pol-language-center.git
cd pol-language-center
```

۲. وابستگی‌های پروژه را نصب کنید:
```bash
npm install
```

۳. سرور توسعه محلی را اجرا نمایید:
```bash
npm run dev
```
اکنون برنامه روی آدرس `http://localhost:3000` در دسترس خواهد بود.

۴. برای ساخت نسخه نهایی آماده انتشار (Production Build):
```bash
npm run build
```
فایل‌های خروجی در پوشه `dist/` قرار می‌گیرند.

## 💡 نحوه استفاده و تست بخش‌های مختلف

- **تغییر نقش سریع (Role Switcher):** در نوار بالای سایت با کلیک روی نمایه کاربر، می‌توانید فوراً بین نقش‌های **زبان‌آموز (Student)**، **استاد (Teacher)** و **مدیر (Admin)** جابه‌جا شوید.
- **داده‌های نمونه (Seed Data):** در صورت نیاز به بازنشانی داده‌ها به حالت اولیه، به مسیر `/dev/seed` مراجعه کرده یا از دکمه تعبیه شده در فوتر سایت استفاده نمایید.
- **کلاس زنده:** با ورود به بخش **کلاس زنده** از منوی اصلی، کلاس فعال همراه با چت و لیست کاربران آنلاین را آزمایش کنید.
